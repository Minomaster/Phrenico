# demo-content/: PLADSHOLDERINDHOLD – IKKE MEDICINSK

Filerne her er opdigtede pladsholdere ("Alfa (demoformel)", "Felt A",
"Symptom 1" …). De bruges kun til at:

- vise designet af formel- og sygdomssiderne (`npm run demo`)
- teste motoren (søgning, sortering, beregning, godkendelsestjek)

Demo-indholdet kan kun vises i en udviklingsversion af appen og har altid et
tydeligt "DEMO"-banner. En udgivet app viser altid kun indholdet fra
`content/`. Demo-filer må aldrig markeres som godkendt; det stopper buildet.
